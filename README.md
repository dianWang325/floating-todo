## 📖 这是什么

很多待办 App 太「重」：要登录、要建项目、要切窗口才能看一眼。
**悬浮待办** 反着来——它是一个**永远飘在桌面上、半透明、不打扰**的小浮窗：

- 写文档、开会、敲代码时，它静静停在角落，**一眼看到今天要做什么**；
- 无需应用账号，**数据优先保存在本机，可选 WebDAV 或局域网设备间同步**；
- 只管「今天 / 明天 / 后天」三天，**专注短期执行**，减少规划负担。

## 🌟 亮点功能

- ⌨️ **全局快捷键秒记**：在任意应用里按 `⌘⇧Space`（Windows 为 `Ctrl+Shift+Space`），浮窗立刻出现并聚焦输入框，打字回车后继续手头的事，零切换。
- ⏰ **自然语言 + 到点提醒**：输入「明天 15:00 提交方案」会自动识别到「明天」分组、设 15:00 提醒，到点弹出系统通知。
- 🔥 **每天打卡连胜**：把习惯设为「每天」常驻待办，完成后累计连续天数（streak），完成时还有撒花动效——把待办和习惯打卡缝在一起。

## ✨ 完整功能

### 待办管理
- ↕️ 拖动待办标题或右侧排序手柄调整顺序，支持各日期和「每天」列表，自动保存；已完成事项保持沉底。聚焦手柄后也可按 `Alt + ↑ / ↓` 排序。
- 📅 **今天 / 明天 / 后天** 三个独立列表，互不干扰。
- ➕ 快速新增、✅ 一键完成（撒花鼓励）、🗑️ 删除；完成的事自动沉底并保留手动排序。
- 🗣️ **自然语言输入**：识别「明天 / 后天」分组、`15:00` / `下午3点半` 等时间。
- 🔔 **可选时间 + 本地通知提醒**，到点提醒你。
- ✏️ 双击标题即可编辑；更多菜单可编辑、加描述、移到其他日期、设为每天、删除。
- 📝 待办描述里的网址**自动变成可点击链接**。
- 🔁 **每天常驻待办** + 🔥 **连续打卡**：跨天不消失、每天自动重置、连胜计数。
- 🌅 **跨天自动滚动**：明天变今天、未完成顺延到今天底部。
- 🧹 一键清除已完成。

### 窗口与外观
- 🌤️ 圆角窗口阴影，可在设置中开启或关闭，重启后保留选择。
- ⌨️ **全局快捷键**唤起并聚焦输入框；`Esc` 收起。
- 📌 始终置顶；🫧 半透明、透明度可调；🎨 自定义背景色 + 跟随系统/浅色/深色。
- 🖱️ 边缘四角拖拽缩放；缩到最小后一键放大；🔽 紧凑模式只显示今天。
- ➖ **迷你悬浮栏（收起态）**：点击面板右上角待办数量（或从左下角缩至最小后继续向右上拖入中心点）即可收起为胶囊悬浮栏，以右上角为锚点停靠；左侧手柄可自由拖拽，中间显示当前日期与未完成数（清零时自动变绿），点击数字即刻恢复完整面板与原尺寸。
- ⚡ **悬浮栏快捷新增态**：在悬浮栏状态点击右侧 `＋` 或按全局快捷键，无需展开主面板即可在下方呼出轻量输入卡，同样支持切换日期、解析时间、`+项目` 与 `#标签`；按 `Enter` 提交后自动收回，按 `Esc` 或点击外部可收起输入框并保留未发草稿。
- 🧭 托盘 / 菜单栏小组件，不占任务栏 / 程序坞。
- 🪟 **Windows 桌面固定**：开启后窗口进入桌面层，按 `Win+D` 显示桌面时仍然可见，但不会覆盖全屏游戏或其他普通窗口；与「始终置顶」互斥。
- 🖱️ **鼠标穿透**：开启后浮窗不再挡点击，点击落到下层窗口；可从托盘菜单随时切回来。
- 🚀 **开机自启动**（可在设置里开关）。

### 应用更新

- 🔔 **新版自动提醒**：启动后及运行期间每 6 小时自动检查更新，发现新版时显示提示，并在设置按钮上显示圆点。
- 🔎 **版本随时查看**：在「设置 → 应用更新」查看当前安装版本，离线也可查看；支持手动检查更新。
- 📦 **一键前往下载**：从设置打开对应的 [Release 页面](https://github.com/dianWang325/floating-todo/releases)，下载适合本机的安装包并安装新版。
- 🛤️ **匹配更新渠道**：正式版接收正式版更新，RC 版本同时接收后续 RC 和正式版更新；检查失败时可在设置中查看原因并稍后重试。

### 数据
- 🗒️ **全局备忘录**：一份不随日期切换的便签，自动保存。
- 💾 **导出 / 导入备份**：导出包含版本历史的 JSON，导入先预览并合并，本机独有事项保留。

### 多设备同步

- ☁️ **自己的 WebDAV，按需开启**：在「设置 → WebDAV 同步与冲突」配置服务地址和同步空间；多台设备使用同一空间即可同步待办、项目、标签、打卡记录、排序与备忘录。
- 📴 **离线照常记录**：修改先保存在本机，开启自动同步后自动上传；恢复网络时补齐变化，设置中可查看待上传数量、上次成功时间和错误，也可立即同步。
- 🔀 **不同事项自动合并**：各设备独立新增、修改的事项汇入同一份清单，重复接收不会重复创建；窗口外观和本机提醒设置独立保留。
- 🕘 **冲突版本可找回**：同一事项并发修改时默认采用最新修改，其他分支仍保留；可保留当前状态、替换成另一版本、编辑后保存，或将冲突任务另存为新任务。
- 🔐 **凭据由系统保管**：WebDAV 密码保存在 macOS 钥匙串或 Windows 凭据管理器；远端同步文件未做端到端加密，应选择可信的服务。详见 [同步使用与协议说明](docs/webdav-sync.md)。

### 局域网与 Tailscale 同步

- 📡 **自动发现设备**：在两台设备的「设置 → 同步与备份 → 局域网与 Tailscale 同步」开启，即可发现同一局域网或 Tailscale／Headscale 网络中的设备；默认显示电脑名称，也可手动输入设备 IPv4 地址查找。
- 🔢 **短码配对，自己掌控**：输入对方的 6 位临时码或 8 位固定码建立配对；临时码每 60 秒更新，固定码重启后保留，支持刷新短码和单独撤销配对。
- 🤝 **多设备共享清单**：配对后合并双方全部待办、项目、标签、打卡记录、排序与备忘录；并发修改保留冲突版本，可在设置中查看和恢复。
- 🔄 **修改后自动同步**：保存后通知已配对设备获取变化，定期检查补齐遗漏，断线重连后继续同步；也可与 WebDAV 同时开启，在设备间传递更新。
- 🔐 **加密传输与凭据保管**：配对设备之间的数据加密传输，配对凭据加密保存在本机，密钥由 macOS 钥匙串或 Windows 凭据管理器保管。
- ⚙️ **按需开启**：默认关闭，使用时需允许本地网络访问和入站 TCP 47831；Tailscale／Headscale 需已登录本机客户端，并允许设备间连接。详细操作见 [局域网同步使用说明](docs/lan-sync.md#使用)。

### 项目与标签
- 🏷️ **符号快捷归类**：输入 `+项目`、`#标签`（含空格或纯数字可用双引号，如 `+"Website Redesign"`）即可归类，支持实时联想补全；新分类随任务提交自动创建。
- 🎨 **卡片底色与标签圆球**：每个任务可归属一个项目并带多个标签（含「每天」常驻待办）；项目赋予卡片专属浅底色，标签显示为彩色圆球，悬停看名称、点击改分类。
- 🔍 **日期内组合筛选**：日期栏下可按项目（含「无项目」）与多个标签组合过滤，切换日期保留筛选；筛选时「清除已完成」仅清理当前可见项。
- ⚙️ **分类管理与备份**：在「设置 → 项目与标签」中改名、自定义颜色或删除分类；导出备份包含分类与配色，旧版数据自动平滑迁移。

## ⚠️ 重要：首次打开被系统拦截怎么办

本应用**没有购买付费签名证书**（macOS 99 美元/年、Windows 也需付费证书）。
因此下载后首次打开可能被系统拦截。“已损坏”也可能表示 App 包签名不完整或文件被修改，应先检查签名，不能仅凭此提示判断文件安全。

### 🍎 macOS
当前构建配置使用 ad-hoc 签名，确保整个 App 包及资源具有可校验的签名；这种签名不认证开发者身份，也不等于 Apple 公证。下载的应用仍可能需要在「系统设置 → 隐私与安全性」中允许打开。

若提示「已损坏」，先检查：

```bash
codesign --verify --deep --strict --verbose=2 "/Applications/floating todo.app"
```

若出现 `code has no resources but signature indicates they must be present`，说明包签名不完整。请使用修复后的构建产物，或从可信源码重新构建。删除隔离属性不会修复签名。

旧版本仅在确认来源与文件可信、且需要本机临时修复时，可先对完整 App 重新签名，再解除该 App 的下载隔离：

```bash
codesign --force --sign - "/Applications/floating todo.app"
codesign --verify --deep --strict --verbose=2 "/Applications/floating todo.app"
# 仅在上面的签名校验成功后执行：
xattr -dr com.apple.quarantine "/Applications/floating todo.app"
```

重新签名仅证明签名后的包结构完整，不能验证下载来源。公开分发要免除未验证开发者拦截，需要 Developer ID 签名及 Apple 公证；参见 [Tauri macOS 签名文档](https://v2.tauri.app/distribute/sign/macos/)。

### 🪟 Windows
若弹出蓝色「Windows 已保护你的电脑 / SmartScreen」窗口：点 **「更多信息」→「仍要运行」** 即可。

> 💡 同一个版本通常只需处理一次。点个 ⭐ Star 支持一下，攒够关注度后我会考虑加上正式签名，免去这些步骤 🙏

## 🛠️ 从源码构建 / 参与开发

```bash
# 前置：Node.js 20+、Rust（https://rustup.rs）
git clone https://github.com/pisceskkk/floating-todo.git
cd floating-todo
npm install
npm run dev      # 开发模式（热重载）
npm run build    # 构建当前平台安装包
```

发布版安装包由 **GitHub Actions** 在打 `v*` tag 时自动构建（macOS + Windows 双平台），见 [`.github/workflows/release.yml`](.github/workflows/release.yml)。

macOS 发布校验会只读挂载最终 DMG，并检查其中 `floating todo.app` 的名称、应用标识与完整签名。仅构建 DMG 时，Tauri 会清理中间 `.app`；校验不依赖该中间目录。

前端回归验证：

```bash
npm ci
npm test
npx playwright install chromium
npm run test:ui
```

Windows 也可设置环境变量 `PLAYWRIGHT_CHANNEL=msedge`，使用已安装的 Edge。浏览器测试会自动启动本地预览服务，覆盖分类输入、日期内筛选、管理、迁移和备份恢复。通知与导入导出原生接口使用测试替身，实际系统通知展示需在桌面应用中验证。

## 🧱 技术栈与架构

- **框架**：[Tauri 2](https://tauri.app)（Rust 后端 + 系统 WebView 前端），安装包小、内存占用低。
- **前端**：原生 HTML / CSS / JavaScript，无打包步骤。
- **持久化**：桌面版 SQLite，旧 `localStorage` 数据自动迁移；可选 WebDAV 与原生局域网同步，密钥存入系统凭据存储。
- **插件**：全局快捷键、系统通知、开机自启、文件对话框。

```
floating-todo/
├─ src/                  # 前端（index.html / styles.css / main.js）
├─ src-tauri/            # Rust 后端、窗口/托盘/快捷键、打包配置
├─ .github/workflows/    # 跨平台自动构建
└─ legacy-macos-swift/   # 早期的 macOS 原生 Swift 版（仅存档参考）
```
