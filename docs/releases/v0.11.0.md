# 待办清单 v0.11.0

主页面提供待办删除选项：任务列表有“删除”按钮，编辑界面有“删除待办”；时间轴、全天任务和月历预览支持右键菜单删除，也支持 Shift+F10 打开任务菜单。

删除需要二次确认，默认聚焦取消，可用 Esc 取消。普通任务从日历、清单中移除；每日重复任务停止所有日期的重复安排。已完成和打卡历史保留并标记“已删除”，其他任务、合集与设置不变。删除使用已有同步版本记录，停止相应提醒；保存失败时保留任务并允许重试。

沿用原有数据库格式。本机升级前备份，程序、任务数据和备份继续位于 D:\software。GitHub Actions 保持关闭，使用本地构建和验证。
