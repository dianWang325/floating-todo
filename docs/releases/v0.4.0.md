# floating todo v0.4.0

v0.4.0 正式版汇集 rc.1–rc.7 的更新，带来迷你悬浮栏、项目与标签、WebDAV 和局域网多设备同步，以及应用更新提醒。

## 功能与体验更新

### rc.1 · 迷你悬浮栏与快捷记录

- 新增迷你悬浮栏，显示日期与未完成数量，点击即可恢复完整面板及原尺寸。
- 悬浮栏支持快捷新增：点击 `＋` 或使用全局快捷键即可记录任务，支持日期、时间、项目和标签，收起后保留未提交的草稿。
- 支持 `+项目`、`#标签` 输入联想、分类配色与组合筛选，以及鼠标拖动和 `Alt + ↑ / ↓` 调整待办顺序。
- 支持可开关的圆角窗口阴影，以及按 `Win+D` 后仍可见的 Windows 桌面固定模式。

### rc.2 · 窗口定位与缩放

- 修正 Windows 桌面固定模式下的窗口坐标处理，保持悬浮栏与面板切换时的位置。
- 改善拖拽缩放结束时的处理，松开鼠标后保留最后一次尺寸与位置变化。

### rc.3 · 界面与显示细节

- 优化 macOS 风格的半透明材质、明暗主题、卡片层次与窗口边缘。
- 调整字体、图标、分类筛选和控件间距，改善 Retina 屏幕上的显示效果。

### rc.4 · WebDAV 同步与冲突恢复

- 支持自建 WebDAV 多设备同步，覆盖待办、项目、标签、打卡记录、排序与备忘录。
- 数据优先保存在本机，离线修改进入上传队列，联网后继续同步；设置中可查看同步状态并手动同步。
- 独立修改自动合并，同一事项的冲突版本可查看、恢复、编辑或另存为新任务。
- 桌面数据使用 SQLite 保存，WebDAV 密码交由系统凭据存储保管；JSON 备份支持版本历史、导入预览与合并。

### rc.5 · macOS 安装与使用指引

- 为 macOS 应用包配置 ad-hoc 签名，并完善首次安装时的签名检查与处理说明。
- 补充悬浮栏操作图示和多设备同步使用说明。

### rc.6 · 局域网同步与应用更新

- 在桌面设置中启用局域网与 Tailscale／Headscale 设备发现，支持手动输入 IPv4 地址查找。
- 支持 6 位临时码、8 位固定码配对及单独撤销设备，配对后的数据加密传输，凭据由系统密钥保护。
- 已配对设备自动合并数据，保留冲突版本，断线恢复后补齐变化，也可与 WebDAV 联动同步。
- 启动后及每 6 小时检查新版；设置中可查看本机版本、手动检查和打开下载页面。正式版接收正式版更新，RC 版同时接收后续 RC 和正式版更新。

### rc.7 · 同步响应与安装包改进

- 保存修改后主动通知已配对设备，定期检查补齐遗漏，并在恢复联网或窗口重新获得焦点时检查更新数据。
- 设备名称默认使用电脑名称，支持自定义，便于识别配对设备。
- 应用及安装器统一使用 **floating todo** 名称，下载附件统一使用 `floating-todo_` 前缀。
- macOS 安装包发布前检查 DMG 内的应用标识与完整签名，并提供英文 README。

## 下载与升级

| 平台 | 安装包 |
| --- | --- |
| macOS · Apple 芯片 | `floating-todo_0.4.0_aarch64.dmg` |
| macOS · Intel 芯片 | `floating-todo_0.4.0_x64.dmg` |
| Windows · 64 位 | `floating-todo_0.4.0_x64-setup.exe` |

升级前退出正在运行的应用。macOS 用户将 `floating todo.app` 拖入「应用程序」；从中文名称版本升级时，移除旧的 `悬浮待办.app`，原有待办数据与凭据继续使用。

macOS 首次打开遇到系统拦截时，请按照 [README 安装说明](https://github.com/pisceskkk/floating-todo/blob/v0.4.0/README.md#-重要首次打开被系统拦截怎么办) 操作。Windows 若被 SmartScreen 拦截，确认下载来源后选择「更多信息 → 仍要运行」。

局域网同步需在两台设备开启，并允许本地网络访问与 TCP 47831；Tailscale／Headscale 需允许设备间连接。WebDAV 远端文件未做端到端加密，请使用可信的服务。
