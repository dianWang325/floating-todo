# 悬浮待办 v0.7.1

打开软件即进入日历主页面。左侧管理合集，右侧安排日程；悬浮窗成为可随时切换的功能。

## 主页面

- 默认打开更大的日历窗口，支持最大化；日、三日、周、月视图及时间轨继续保留。
- 左侧导航包含日历、完成记录、提醒中心及合集，底部提供悬浮窗模式和设置与同步入口。
- 主页面作为普通应用显示在任务栏，不应用悬浮窗的鼠标穿透、桌面固定和置顶偏好；切回悬浮窗后恢复原偏好。
- 右上角 × 隐藏到托盘。Esc 关闭当前编辑状态，切换悬浮窗使用明确的侧栏入口。
- 设置中可选择启动视图，默认是主页面。

## 合集

- 从侧栏 ＋ 创建合集，支持名称、颜色、重命名和删除。
- 选中合集后，四种日历及完成记录只显示该合集的任务；新建任务默认属于当前合集。
- 全部任务与未分类入口方便查看所有安排。
- 原有项目保留原标识、颜色、任务关系及同步历史，并直接显示为合集，无需重新分类。
- 删除合集需要在界面内确认，任务移到未分类，任务本身与完成历史均保留。
- 继续使用现有同步协议，合集在旧版本中显示为项目。此版本提供单层合集，不引入文件夹层级。

布局参考滴答清单的侧栏分类和日历筛选交互：[官方帮助](https://help.dida365.com/articles/6950670128287580160)。

## 验证与升级

- 单元测试覆盖合集兼容、重名校验、删除保留任务及同步历史。
- 浏览器交互验证启动、合集管理、筛选、主页面/悬浮窗切换、设置和窄窗口布局，并回归既有任务、提醒和同步功能。
- Windows 原生验证启动主页面、合集创建删除、最大化/还原、悬浮栏、快速捕获、时间轨、完成记录和窗口尺寸恢复。
- 本机升级遵循既有 D 盘安装与数据约定：显式指定原安装目录，升级前备份，升级后核对数据库和目录链接；不要删除指向数据目录的链接。

- 补充同步同名分类的标识归并，以及删除后重建同名合集的兼容验证。
