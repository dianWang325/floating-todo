# 待办清单 v0.13.0

- 新增项目视图，沿用既有 # 标记，无需迁移任务；同一项目汇总同合集或跨合集、任意日期的任务，一个任务可属于多个项目。
- 项目展示任务完成进度，支持按合集、状态和关键词筛选，包含已完成及已归档任务；每天重复任务按当天打卡状态展示。
- 项目可记录预期完成日期、项目说明与想法、预期进度节点；这些笔记不自动生成待办。
- 支持直接创建暂未有任务的项目，以及从项目新建已关联的任务；日历新建、编辑支持 # 项目与多选关联。
- 项目笔记随备份和同步保存，切换项目或视图保留草稿，失败可重试；完整保留现有任务、完成记录和设置。
- 仅本地 Windows 构建；GitHub Actions 保持关闭，程序和数据继续保留在 D 盘。
