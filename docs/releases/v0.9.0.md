# 悬浮待办 v0.9.0

Windows 主页面使用系统原生标题栏，右上角提供标准的最小化、最大化/还原和关闭按钮。

- 最小化到任务栏，支持系统窗口管理和标题栏的双击最大化/还原。
- 关闭主窗口前等待本地数据保存，窗口保留在托盘中继续提醒；未提交的编辑草稿随后台窗口保留。
- 保存失败时保留窗口并提示原因，避免无声丢失数据。
- 完全退出仍可使用托盘菜单“退出”。
- 切换悬浮模式后恢复无边框和原有悬浮窗位置、大小及置顶等设置。
- 最小化后通过托盘或全局快速捕获快捷键唤起时，恢复窗口显示。
- 主页面启用系统标题栏后隐藏重复的页面内窗口按钮；浏览器预览保留三键布局。

验证包含标题栏开关、关闭前保存及草稿保留，以及 Windows 原生窗口的最小化、恢复、关闭到托盘、重新显示、最大化和悬浮模式回归。

仅发布 Windows 版。升级继续沿用本机的 D 盘程序、数据和备份目录，并验证任务、合集、完成历史和设置完整。
