# 悬浮待办 v0.5.0：日历、完成回顾与提醒增强

## 新增

- 主面板新增「日历与回顾」入口。桌面窗口展开为较大日历，退出后恢复原尺寸与位置；小窗口自动采用上下布局。
- 月历支持跨月、跨年查看和任意日期新增任务，显示每日已完成与未完成数量；支持编辑标题、描述、日期、时间、项目和提前提醒。
- 「完成记录」支持日期范围、近 7 天、关键词与项目查询，显示普通任务及每天打卡、完成次数与活跃日。
- 新的完成操作记录实际完成时间和日期；普通任务保留原计划日期。重新打开后从当前完成统计中移除，状态变更可在任务编辑中查询。
- 「清除已完成」改为「归档已完成」，归档任务仍可在日历与历史中查询并重新打开。删除任务保留的完成记录标注为已删除。
- 提醒支持提前 5/10/15/30/60 分钟或 1 天；「提醒中心」可测试系统通知、开关本机提醒，并将最近的提醒延后 10 分钟。
- 仅在通知接口成功返回后记录已发送；拒绝权限、发送失败或保存失败保留重试机会。应用重新运行、重新聚焦、恢复可见和定期检查时补查遗漏，已发送记录本机持久化。
- 保留本 fork 已有的标签名称和彩色标记展示。

## 升级与数据

- 兼容旧版本地快照与现有 v3 SQLite 数据。首次从旧版迁移时保留原始快照；导出备份保留任务版本历史。
- 已丢弃的旧任务不能自动恢复；旧任务没有准确完成时间时明确标为未知，按原计划日期展示，不推造完成时间或历史打卡。
- 普通任务按当前完成状态计一次，每天打卡按日期计一次；重新打开会调整统计。此版不提供容易混淆的“完成率”。
- 更新检查指向 `dianWang325/floating-todo`，这是基于 `pisceskkk/floating-todo` 的定制发行版。

## 提醒边界

- 请保持应用在系统托盘运行，允许系统通知。应用完全退出、电脑睡眠或关机期间不会准时提醒，恢复后再检查遗漏；没有增加退出后的系统计划任务。
- 普通任务补查未发送的到期提醒；每天任务补查今天和前一天，并检查次日的跨午夜提前提醒。通知可能被系统免打扰隐藏，“已发送”不代表用户已看到。
- 提醒发送记录和稍后提醒属于本机状态，不在设备之间同步。

## 验证

- Node 单元测试：任务迁移、任意日期、完成与归档、跨日打卡、时区、跨午夜提前提醒、拒绝通知权限、失败重试与去重。
- Playwright：月历创建与编辑、历史查询与重新打开、小窗口与键盘操作、提醒中心，以及既有功能回归。
- 发布工作流构建 Windows 和 macOS 安装包，并在发布前运行 Rust 测试、Windows 原生窗口冒烟及 macOS 安装包签名完整性检查。
