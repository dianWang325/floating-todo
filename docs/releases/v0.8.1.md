# 悬浮待办 v0.8.1

主页面采用参考苹果日历的视觉风格，合集可通过右键菜单直接调整颜色。

## 日历外观

- 浅灰侧栏、白色日历画布、细分隔线和更简洁的工具栏。
- 月份标题更醒目，日期放在单元格右上方，“今天”使用红色圆形标记。
- 月历事件条、全天任务和时间轴事件使用所属合集的颜色。
- 小月历移入主侧栏，时间轴获得更宽的显示区域。
- 保留日、三日、周、月切换、窗口最大化及浮窗功能，并适配浅色、深色和系统主题。
- 样式只作用于日历主页面，悬浮窗的外观偏好仍然保留。

## 合集右键菜单

- 右键合集名称即可选择红、橙、黄、绿、蓝、紫、灰等预设色，或使用自定义颜色。
- 颜色通过现有合集版本记录保存，继续支持既有多设备同步协议。
- 右键未选中的合集不会改变当前筛选；修改颜色不修改任务内容。
- 支持 Shift+F10、方向键、Enter、Esc，以及点击菜单外关闭；菜单会避开窗口边缘。
- 当前任务输入草稿及合集编辑状态在打开菜单和改色时保留。

交互参考：[Apple Calendar 官方的日历颜色与快捷菜单说明](https://support.apple.com/en-in/guide/calendar/icl1030/27.0/mac/27)。

- 回归任务、分类、同步、提醒、时间轴和窗口切换测试。
- 新增颜色保存与重启保留、草稿保留、筛选不变、任务内容不变、键盘菜单、边缘定位及浅深色视觉验证。
- Windows 原生验证增加右键合集并选择颜色。
- 本机继续安装在 D 盘原目录；升级前备份程序和数据，升级后核对版本、目录链接、数据库完整性和任务设置保留情况。
